Dataset Overview

The public-facing dataset view is powered by a structured statistical model. Users see simple tables and indicators while the underlying dataset is organized through SDMX concepts.

SD
Structured statistical data

This dataset uses a Dataflow → Dimensions → Geography → Time → Observation structure. The technical SDMX layer remains underneath the public interface and can later connect directly to trsbsR, the TrSBS API and the statistical database.
